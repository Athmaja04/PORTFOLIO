# Athmaja K A - Personal Portfolio

A sleek, responsive, and modern personal portfolio website showcasing my skills, experience, and projects as a Computer Science student and aspiring Software Engineer.

## Live Demo

This static HTML/CSS/JS site is designed to be hosted via **GitHub Pages**. (Link to be added once deployed).

## Features

- **Responsive Design**: Fluidly adapts to both desktop and mobile screens.
- **Modern UI**: Uses a deep slate dark mode aesthetic with glassmorphism components.
- **Scroll Animations**: Smooth fading and sliding elements triggered on scroll using the Intersection Observer API.
- **Semantic Structure**: Written in pure HTML5, CSS3, and ES6 Javascript.

## Local Development

If you'd like to run or view the site locally:
1. Clone the repository: `git clone https://github.com/Athmaja04/PORTFOLIO.git`
2. Navigate into the directory.
3. Open `index.html` in your favorite modern web browser. (No build tooling or local dev server is strictly required!)
